# Scripts

A collection of utility scripts organized by language/platform.

## Structure

| Directory | Description |
|-----------|-------------|
| [bash/](bash/) | Bash shell scripts for Linux/macOS |
| [powershell/](powershell/) | PowerShell scripts for Windows/cross-platform |

## Adding a Script

1. Create a subfolder under the appropriate language directory (e.g. `bash/my-script/`)
2. Add the script file and a `README.md` using the template in that directory's README
3. Add a row for it in the language directory's index table
